## Airbnb Application Deployment using Docker and Ansible on AWS

### Technologies Used

* AWS EC2
* Ansible
* Docker
* PostgreSQL
* Java 21
* Spring Boot
* Maven

### Features Implemented

* Automated Java installation using Ansible
* Automated Docker installation using Ansible
* Containerized Spring Boot application
* PostgreSQL container deployment
* Docker networking configuration
* Application deployment and troubleshooting
* Production-style log analysis and debugging

### Architecture

AWS EC2
→ Docker Engine
→ PostgreSQL Container
→ Spring Boot Container
→ Docker Network
→ REST APIs

### Outcome

Successfully deployed and executed a real-world Airbnb Spring Boot application in Docker with PostgreSQL connectivity on AWS EC2.
